# Testing

Test observable behavior, not implementation wording. Cover success, failure, boundaries, and confirmed-bug regressions. Match test depth to risk: targeted tests for low risk; unit/integration plus regression checks for medium; negative/adversarial and migration/rollback validation for high risk.

Use harmless synthetic data and isolated environments. Record command, result, scope, and unverified gaps. Do not describe simulated checks as live agent, runtime, or production tests.
