# Skills

A small, growing collection of reusable AI skills: focused instruction packages with supporting references and optional local validation tools.

## Available skills

- [Human-Centered Writing](human-centered-writing/README.md) — draft or revise accurate, natural, audience-aware prose while preserving voice, meaning, and protected details.
- [Vibe Coding](vibe-coding/README.md) — build, extend, secure, test, and document software through a risk-aware engineering workflow.

Each skill is self-contained in its own directory so future skills can be added without reorganizing the repository.

## Install and use

Copy one complete skill directory—keeping its `SKILL.md` and supporting resources together—into the skill location supported by your agent platform. See the individual skill README for platform guidance and local validation commands.

For Vibe Coding, invoke `$vibe-coding` where supported or ask the agent to use the Vibe Coding Skill for a substantive software task. It will classify risk, load only relevant security and engineering guidance, and report verified results and limitations.
