# Voice Preservation

## Read before revising

Identify the author’s perspective, audience relationship, formality, vocabulary, sentence complexity, pacing, punctuation, paragraph habits, and distinctive expressions. Distinguish an authorial choice from an accidental error or mismatch with the requested context.

## Edit conservatively

Keep unusual but valid phrasing, regional language, learner identity, and deliberate informality when they serve the author and audience. Change only what impairs meaning, accuracy, readability, or the stated goal.

## Protect meaning

Preserve names, dates, amounts, units, legal and technical terms, quotations, citations, URLs, code, and formatting. Never add a personal story, emotion, accomplishment, source, or outcome. When a requested change needs missing facts, ask or use an explicit placeholder.

## Voice sample handling

Use supplied samples to identify patterns, not to claim the final text was written by the source author. Do not imitate a living person in a deceptive manner. A sample should guide register and observable style, not override truth or task constraints.

## No-change decision

When a passage already meets the brief, return it unchanged. If the user asked for reasoning, briefly state that no material change would improve it.
