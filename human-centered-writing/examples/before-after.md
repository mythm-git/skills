# Before-and-After Examples

These are editorial demonstrations, not detector tests. Protected facts and intended meaning remain unchanged.

## Casual English

**Before:** “I wanted to reach out and let you know that I might be late because traffic is really bad.”

**After:** “I’m running late. Traffic is backed up, but I should be there soon.”

Changed the generic preface; retained the uncertainty and reason.

## Professional email

**Before:** “I am writing to kindly follow up regarding the proposal that I sent last week.”

**After:** “I’m following up on the proposal I sent last week. Do you have any feedback or a decision timeline?”

Made the purpose and next action specific without adding pressure.

## German, formal

**Before:** “Ich möchte Ihnen mitteilen, dass ich mich bezüglich des Termins bei Ihnen melden wollte.”

**After:** “Ich melde mich wegen des Termins. Passt Ihnen Dienstag um 10 Uhr?”

Preserved the **Sie** register and made the request concrete.

## Technical explanation

**Before:** “The API is very robust and seamless because it enables users to leverage authentication.”

**After:** “The API requires an access token on protected endpoints. Clients send the token in the `Authorization` header.”

Replaced unsupported marketing language with the supplied technical mechanism. Code syntax remains protected.

## Formulaic text

**Before:** “In today’s fast-paced world, effective planning is crucial. First, set goals. Second, track progress. Finally, celebrate success. In conclusion, planning is important.”

**After:** “Planning works best when the goal and next step are clear. Track progress if it helps you adjust the plan.”

Removed generic framing, a forced list, and repetition; did not add facts.

## No-change decision

**Before and after:** “The build failed on 12 October 2026 because `config.yaml` was missing. Restore that file, then rerun `npm test`.”

No rewrite is needed: it is precise, concise, and preserves an exact date, path, and command.
