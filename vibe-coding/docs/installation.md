# Installation

## Codex

Use the skill mechanism exposed by your installed Codex surface or workspace. For local filesystem discovery, place the `vibe-coding` folder in the configured Codex skills directory and restart/reload if required. In managed product surfaces, import/upload it through the available skills or plugin workflow. Confirm discovery with a harmless request, then run the included Python checks only after the environment permits script execution.

## Claude Code and Claude

Use the Skills workflow exposed by the installed Claude Code release or Claude product. Import the folder/package where that surface accepts custom skills. Claude documentation describes custom skills as requiring the applicable capability and code execution; do not assume filesystem execution permission. Test with a non-mutating request and record the result in the compatibility matrix.

## ChatGPT

In eligible workspaces, use Plugins → Skills → Create → Upload from computer, or create with the Skills editor/chat. Workspace administrators may need to enable creation, upload, use, or installation. An upload scan and a visible skill do not prove shell/filesystem script execution; use the skill as instructions if execution is unavailable.

These are reproducible verification steps, not claims of completed installation. Consult your current product UI and administrator policy because availability changes by plan, region, surface, and rollout.
