# Improvements — v0.2.0

## Delivered

- Replaced broad default reference loading with conditional routing. Meaningful work still always loads the security applicability matrix and verification-status guidance; requirements and architecture references load only for medium/high-risk, unclear, existing-system, shared-interface, or multi-file work.
- Removed release documentation's obsolete claim that Git was intentionally uninitialized.
- Repointed public documentation away from private verification paths and added sanitized public reports.
- Updated tests to validate the new routing and release version.

## Efficiency evidence

The routing table changed from four default references for every meaningful change to two required references, with two formerly-default references made conditional. This is a structural reduction in default reference loads; no token percentage is claimed because the current environment did not expose reliable comparable token accounting.
